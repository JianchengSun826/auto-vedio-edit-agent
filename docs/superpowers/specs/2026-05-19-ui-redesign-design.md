# UI 重设计：功能按钮 + 进度条

**日期：** 2026-05-19  
**主要改动文件：** `app/main.py`、`agent/orchestrator.py`

---

## 目标

1. 上传视频后展示功能快捷按钮，引导用户操作
2. 按钮支持多选，多选后合并执行所有规则
3. 处理过程显示步骤条 + 进度条
4. 所有功能均返回多个独立片段供用户审核下载，不自动拼接

---

## 页面结构（单页，从上到下）

### 区域 ① — 上传与功能选择（始终可见）

**左侧：**
- 视频上传组件（`gr.Video`）
- 上传后显示视频预览

**右侧：**
- 4 个功能按钮，**支持多选**，选中后高亮（蓝色边框 + "已选"标签）
- 选中按钮后在按钮内部展开参数输入区
- 「或者」分隔线
- 自定义文字输入框（AI 解析，付费）
- 付费说明常驻信息框（绿色边框）
- 「🚀 开始分析（已选 N 个功能）」按钮

**「开始分析」触发条件：**
- 有至少一个按钮被选中，或文字输入框有内容
- 视频已上传

## 四个功能按钮详细说明

### 🔍 关键词提取（免费）
- 选中后展开：关键词输入（逗号分隔）、前留秒数、后留秒数
- 执行：`KEYWORD_MATCH` 规则，无需 LLM
- 返回：每个命中片段作为独立条目进入审核表

### 🎙 按说话人剪辑（免费）
- 选中后：先执行转录，完成后展开说话人选择器（`gr.CheckboxGroup`，列出所有检测到的 SPEAKER_xx）
- 执行：`SPEAKER_FILTER` 规则，无需 LLM
- 返回：每位说话人所有发言片段各自作为独立条目；结果区按说话人分组显示，每组可单独下载

### ⏱ 截取时间段（免费）
- 选中后展开：起始时间（秒）、结束时间（秒）
- 执行：`TIME_RANGE` 规则，无需 LLM
- 返回：指定范围的一个片段

### ✂️ 去除静音（免费）
- 选中后无需额外参数，直接触发
- 执行：`SILENCE_CUT` 规则（FFmpeg 检测音量低谷），无需 LLM
- 返回：每段连续有声内容作为独立片段进入审核表，**不自动拼接**

## 付费 AI 解析（文字输入框）

适用于按钮无法满足的复杂需求。

**常驻信息框文案：**
```
ℹ️ 使用 Claude AI · 少量费用
10分钟 ≈ ¥0.03 · 1小时 ≈ ¥0.28

适合：
• 理解模糊描述（"找情绪激动的片段"）
• 口语时间描述（"截取前五分钟"）
• 去除口误和重复片段（自动识别说错重说、语义重复）
```

**执行：** 调用 `IntentParser`（Claude Haiku），生成完整 `EditPlan`，然后执行规则引擎。

---

## 多选按钮组合规则

多个按钮同时选中时，规则按以下顺序叠加执行：

1. `KEYWORD_MATCH` / `SPEAKER_FILTER` / `TIME_RANGE` — 产生候选片段
2. `SILENCE_CUT` — 对候选片段做静音切割
3. `_merge_overlapping` — 去重合并（RuleEngine 现有逻辑）

例：关键词提取 + 去除静音 → 先找到关键词片段，再对每个片段去静音，返回多个子片段。

## 说话人剪辑特殊流程

因为说话人 ID 在转录前未知，按说话人剪辑需要两阶段交互：

```
用户选中「按说话人剪辑」按钮
  → 点击「开始分析」（第一次调用）
  → 后端执行转录（WhisperX），返回说话人列表
  → 前端展示说话人选择器（gr.CheckboxGroup，列出 SPEAKER_00、SPEAKER_01...）
  → 用户勾选说话人后点「确认筛选」（第二次调用）
  → 后端执行 SPEAKER_FILTER 规则，返回结果
```

这是两次独立的函数调用，不是同一个生成器中途暂停。第一次调用完成后进度条显示"转录完成，请选择说话人"并等待用户操作。

## 区域 ② — 处理进度（点「开始分析」后出现）

**步骤条（3 步）：**
- ① 音频转录 → ② 解析意图（仅文字输入路径）→ ③ 执行规则
- 按钮路径跳过"解析意图"步骤，步骤条直接从 ① 跳到 ③

**进度条：** 使用 `gr.Progress`，生成器函数 `yield` 各步进度：
```python
progress(0.1, desc="正在转录音频…")   # WhisperX
progress(0.6, desc="正在解析意图…")   # 仅 LLM 路径
progress(0.9, desc="正在执行规则…")   # RuleEngine
progress(1.0, desc="完成")
```

**区域 ② 在处理完成后被区域 ③ 替换（`visible` 切换）。**

## 区域 ③ — 结果审核与导出（完成后出现）

- 步骤条全绿 + "找到 N 个候选片段"
- `gr.Dataframe`：列：序号 / 说话人 / 时间范围 / 内容预览 / 置信度 / 包含（勾选）
- 说话人剪辑结果按说话人分组显示
- 导出平台多选 + 「批准并导出」按钮
- 导出文件列表（`gr.File`，支持逐个下载）
